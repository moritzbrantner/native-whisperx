Browser runtime acceptance

This page exercises the deployed /transcribe/ workbench itself. Choose a real local audio file inside the embedded workbench, run browser transcription, and optionally enable post-ASR translation before the run. The file and transcript stay local to the browser. Browser model execution must use WebGPU and must not use a server, CPU inference provider, or Python fallback.

  1. Confirm the embedded workbench reports WebGPU ready.
  2. Choose a real local spoken-audio file.
  3. For translation acceptance, enable Translate after transcription and verify the model/source/target settings.
  4. Run the browser workflow and wait for Finished locally.
  5. Optionally exercise the Native JSON and SRT download buttons in the workbench.
  6. Click Capture acceptance evidence and save the JSON report.

A transcription-only run can still pass #272. When translation is enabled, the same evidence additionally requires local translation completion and a separately preserved source transcript for #286.
