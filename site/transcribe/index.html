Browser transcription · experimental

Transcribe audio locally with WebGPU

Select an audio file, load a small Whisper model into the browser, and run speech recognition on your GPU. Audio stays on this device; browser runtime and model assets are downloaded as needed.

Runtime boundary

This page is the executable WebGPU acceptance harness for issue #272. The current reference inference runtime is Transformers.js WebGPU. The Rust/Burn WASM provider is tracked upstream in audio-analysis #51 and will replace this reference runtime after its wasm32 gate is green.

No silent server, Python, CPU, alignment, diarization, or translation fallback is used.

Why the reference runtime exists

It proves the product slice independently: GitHub Pages delivery, WebGPU detection, local audio preparation, model download/cache, timed transcript rendering, and export. The reusable Rust inference mechanics remain owned by audio-analysis, so native-whisperx does not absorb a second ASR implementation.
